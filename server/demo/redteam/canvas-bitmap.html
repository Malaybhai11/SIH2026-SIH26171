Scanned form preview

This PII is drawn onto a <canvas> as pixels by the script below — there is no DOM text node containing it anywhere, the same way a scanned photo of a form has none. No text-based rule can see it; this is exactly what on-device OCR (A1) exists to close. Expected to leak until A1 ships — this page exists to make that honest, not to hide it.
