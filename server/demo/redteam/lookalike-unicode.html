The email below LOOKS like plain ASCII but uses a Cyrillic "а" (U+0430) in place of Latin "a" (U+0061) — invisible to the eye, invisible to a strict [A-Za-z] character class. A known, documented limit of regex-based detection, not something this page pretends is fixed. The phone number below is written with full-width digits (U+FF10-FF19) for the same reason.
